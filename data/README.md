# Dataset

This project uses a simulated global supply chain dataset containing 5,000 shipment records.

The analysis covers shipment records from 2024 to 2025 and includes variables related to:

- Origin and destination ports
- Transport mode
- Product category
- Shipment distance and weight
- Weather conditions
- Fuel price index
- Geopolitical risk
- Carrier reliability
- Shipment disruption
- Lead time

The dataset was obtained from Kaggle.

> Note: The dataset is synthetic and is used for analytical and portfolio purposes.
